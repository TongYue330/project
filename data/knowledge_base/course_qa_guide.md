# 课程作业 AI 答疑助手资料

本系统面向在校大学生，核心流程是提交文字题目，系统检索课程资料后生成分步骤解答。回答应帮助学生理解思路，而不是只给出一个结果。

系统使用 Flask 提供 Web 页面，使用 SQLite 保存题目和回答记录。题目记录包含输入类型、题目内容和创建时间；回答记录包含回答文本、步骤、置信度和低置信度标记。

当资料不足、题目表述不清或模型服务不可用时，系统应明确提示用户补充信息或稍后重试，不能编造资料来源。AI 生成的内容仅供参考，复杂题目建议与老师或同学核对。

本项目当前聚焦数学和计算机相关作业，支持文字输入和历史记录查看。后续可接入图片 OCR、向量检索、针对单步追问和课程资料更新功能。
